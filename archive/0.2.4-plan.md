# 0.2.4 — Read the rhythm

The Sound tab places a two-bar kick and snare grid below each study’s description. It shows four steps per beat in groups, with filled cells for hits. The grid depicts only these two percussion parts, not the full arrangement. An accessible description gives the kick and snare counts in each bar.

The grid and Web Audio scheduler use the same score data, including the shared backbeat when a study does not specify its own drums. The grid is static and can be read without starting playback. Hip-hop’s study has offbeat kicks so its audio and diagram match the written description.

## Acceptance and manual pass

1. On desktop and a 320 px screen, open Sound and verify that both measures, labels and beat groups fit. Check that a screen reader has access to the individual hit positions as counts.
2. Compare House’s steady kick, Hip-hop’s offbeat kicks, and Jungle’s displaced kicks and snares. Toggle playback, change styles, and verify that the grid always depicts the currently selected score.
