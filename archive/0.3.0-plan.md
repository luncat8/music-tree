# 0.3.0 — A fourth generation and a depth-aware map

## Depth as the map's own dimension

The atlas carries fourteen genres over four generations: blues at the origin, jazz, R&B and rock as branches, their styles, and a fourth row of offshoots — disco, hip-hop, jazz fusion and alternative rock. A genre keeps one primary parent so the tree stays readable, and records every additional influence separately, including ones that cross between families: funk and soul into disco, disco and jazz into hip-hop, rock and funk into jazz fusion, metal into alternative rock.

The map no longer assumes three columns. It measures the deepest parent chain once at boot, spreads one column per generation evenly across the visible plot, and derives node width from the gap between columns so a fourth generation stays legible on a phone. Generation headings are built from the catalog's `generations` labels instead of from markup, so a fifth generation needs a catalog entry and nothing else. A branch filter hides unrelated nodes but keeps the column geometry, so filtering never re-flows the remaining tree.

## Records and studies

Each new genre carries the same editorial record as the earlier ones: family, date, place, a shift narrative, core and additional instruments, techniques, characteristics, a landmark recording and a study piece. Instruments that first appear in the fourth generation — drum machine, sampler, turntables, synthesizer, strings — have their own Wikipedia slugs, and every new genre has a distinct two-bar study whose tempo, timbre and chord placement follow its style.

Cross-influence notes are written from the receiving genre's side, so a profile answers "what did this borrow" before it answers "what did it lead to". Alternative rock keeps punk as its parent and treats rock and metal as additional influences; hip-hop keeps funk as its parent and treats disco, soul and jazz as additional influences.

## Acceptance and manual pass

1. Open `index.html` directly over `file://`; confirm four generation headings, fourteen nodes and no clipped labels from 320 px up to wide desktop.
2. Select Disco, Hip-hop, Jazz fusion and Alternative rock; check the profile header, influences, core instruments, both listening pieces and that each plays its own pattern.
3. Select Disco, then Hip-hop: the cross-branch arc should brighten while the rest stays quiet.
4. Filter by each branch; confirm the columns keep their positions and unrelated nodes disappear without re-flowing the rest.
5. Confirm no external request fires on boot and that the guide copy matches the current volume.
