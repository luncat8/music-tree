# 0.2.7 — Cuban dance lineages

Add Danzón as an independent root alongside Son cubano. Danzón leads to Mambo and Cha-cha-chá; Son and Jazz influence Mambo, Mambo influences Cha-cha-chá and Salsa. These primary routes simplify a shared history without presenting Danzón as a child of Son. Keep all existing file numbers and append the new records. The Afro-Cuban filter shows both roots.

Each file includes instruments, distinguishing musical features, two recording references and an original two-bar synthesized study. Compare Mambo's clave sketch with Son; use contrasting cinquillo and triple-step sketches for Danzón and Cha-cha-chá. The kick and snare grid represents synthesized accents, not a transcription of actual Cuban percussion instruments. Normalize diacritics in catalog search so both accented and unaccented names, instruments and recording credits work.
