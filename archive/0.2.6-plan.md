# 0.2.6 — Country branches

Extend the Country root with connected files for honky-tonk, outlaw country, country rock and alternative country. Preserve the independent root and existing Bluegrass route. Use one primary parent per file for the solid lineage, and represent meaningful cross-family influence with dashed links rather than making the tree imply a single origin.

| File | Parent (solid) | Additional influences (dashed) |
|---|---|---|
| Honky-tonk | Country | — |
| Outlaw country | Honky-tonk | — |
| Country rock | Country | Rock |
| Alternative country | Country rock | Alternative rock, Punk |

Each file includes a concise historical and musical distinction, instruments, techniques, traits, two recording references, and an original two-bar study. The new studies are covered by the same score-driven audio and rhythm-grid checks as the existing catalog. Append the records to retain all existing file numbers. The deeper Outlaw country route adds no map generation; layout remains data-derived.

Search keeps its existing behavior, including showing the full catalog for an empty query. The catalog and feature files already have clear ownership, so this change needs no broad refactor.
