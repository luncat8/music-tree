# 0.2.5 — Compare profiles along the Kingston lineage

A fresh explorer opens Jazz on Overview. Overview, Sound and Listening are choices for browsing the atlas, not properties of individual genres. Selecting a node, following a lineage link, changing branches or opening a search or index result renders the new file in the active tab. The tab stop, selected indicator and panel label all follow that choice. A genre change stops playback; it never starts the next study.

## Selected route

R&B → Ska → Rocksteady → Reggae → Dub traces one route into and through the Kingston studios. The ska file also credits mento and jazz; rocksteady credits soul vocal groups. A dashed link from Dub to Jungle connects the studio and sound-system traditions to the UK route. The four files follow the original twenty in catalog order so existing file numbers stay stable.

Each file pairs a landmark recording with a piece to learn. The playable studies compare ska’s clipped offbeats and walking bass, rocksteady’s slower melodic bass, reggae’s one drop and a dub version of the reggae study. The last two use the same bass and drums, so the chord mutes and echo-like repeats are audible against a familiar backing.

## Acceptance and manual pass

1. On a fresh `file://` load check Jazz / Overview, the local fonts and 24 nodes. At phone and desktop widths, check card labels, Fit and the R&B filter.
2. Choose Sound and compare the Ska and Rocksteady map nodes. Play Reggae, then jump to Dub using `/`: Sound stays selected, the study changes but the one-drop grid matches, and the player is idle.
3. Use the arrow keys to select Listening and open a different genre from the index. Verify both recording credits belong to the new genre. Return to Overview and follow Dub → Jungle and the influence link back.
