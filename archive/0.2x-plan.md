# 0.2x — Labels that fit and a wider tree

Map cards keep a fixed height whatever their label length. The layout owner measures each rendered name against the card’s text column and reduces the font size until the name fits on one line, with a floor of 8 px for legibility. Card geometry — slot height, branch curves and the reveal bounds — reads the card box, not the rendered text, so a longer name never pushes its row into the next one.

The stylesheet keeps the same maximum sizes it always had: a name no wider than its card is drawn at the established scale and is not shrunk. Padding, the family glyph and the gap between them are slightly tighter so more of a narrow card is available to text.

## Acceptance and manual pass

1. On a fresh `file://` load check Jazz / Overview, the local fonts and 31 nodes over nine generation columns. At 320, 768, 1280 and 1920 px, confirm every card keeps the row height of its neighbours and that no name wraps or spills outside its card.
2. Open Breakbeat hardcore (labelled “Hardcore”) and Jungle at a narrow width: the labels shrink rather than wrap, and the cables still meet the card edges.
3. Fit the map, drag to the last column and select the deepest column: the camera reveals the card without shrinking it.
4. For each new file read all three tabs, play the study and check that the rhythm grid matches the drum hits in playback. Confirm the branch filter still hides unrelated nodes and keeps the origin.
5. Search `bristol sound`, `liquid dnb`, `math-rock` and `Kingston`; each returns the expected first hit.
